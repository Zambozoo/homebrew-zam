# Homebrew Tap for Zam
![Zam Logo](assets/logo_banner.png)
Official [Homebrew](https://brew.sh) tap for the [Zam](https://github.com/Zambozoo/zam) programming language.

## Installation

You can install `zam` directly using Homebrew on macOS or Linux (including WSL):

```bash
brew install Zambozoo/zam/zam
```
Or, tap the repository first and install:

```bash
brew tap Zambozoo/zam
brew install zam
```

## Verification
Once installed, verify the installation by checking the version:

```bash
zam --version
```
## Maintenance & Updates
To update zam to the latest release:

```bash
brew update
brew upgrade zam
```

For issues, feature requests, or documentation regarding the language itself, please visit the [zam repository](https://github.com/Zambozoo/zam).
